# Agenda Virtual Suconor
## <img alt="Icone-Ideia" width="30" src="https://img.icons8.com/?size=100&id=21083&format=png&color=000000"/> Sobre o Projeto 
  <strong><div>
    <p> O projeto surgiu com o objetivo de centralizar as informações de contato
        em uma interface simples, intuitiva e de fácil acesso, permitindo que os
        colaboradores localizem rapidamente ramais e informações associadas aos
        diferentes setores da organização.
        
  A aplicação foi desenvolvida com foco em **usabilidade, organização das
  informações, facilidade de manutenção e segurança no controle de acesso**,
  servindo também como um projeto prático para aplicação de conceitos de
  desenvolvimento web e engenharia de software.
   </p>
